YouTube Music Visualizer Test Page

This page helps test the visualizer functionality outside of YouTube Music.

Note: This is for development testing only. The actual extension works on music.youtube.com

Instructions:

  1. Load a local audio file or use the default test sound
  2. Click "Start Visualizer Test" to initialize
  3. Play the audio to see the visualization
  4. Use "Toggle Visualizer" to test the on/off functionality
